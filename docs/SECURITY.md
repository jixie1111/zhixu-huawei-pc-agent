# 安全边界

## 明确授权的资料包

公开完整资料必须同时具备持有人授权、独立导出包和逐文件校验清单。PUBLIC_DEPLOYMENT 本身不会开放 private 目录；有效的 PUBLISHED_DATA_DIR 才启用授权库模式。

只读事务导出当前业务表，保留作品与版本关系；不上传SQLite、WAL、已删除页、日志、缓存、平台凭据或账号配置。打包扫描配置中的真实秘密与常见令牌格式，遇到疑似凭据停止，不输出其内容。

服务端仅按文档/图片ID访问已索引文件。资料路径不接受客户端传入，不跟随符号链接；原始HTML资料作为文本呈现，不作为页面执行。发布包启动时校验所有清单文件并拒绝额外文件。

## 每位访问者的连接

线上模型连接由使用者在页面填写，初始为空。浏览器为创作空间持有随机访问凭据，模型Key只在当前访客的服务端内存会话中使用；不持久化到浏览器、数据库或仓库。两小时空闲或重启后失效。状态只返回配置标记与非秘密连接信息，错误脱敏。

公开发布不继承运营者的环境模型密钥。模型地址仅接受已支持的官方HTTPS主机，拒绝localhost、局域网、非标准端口、URL凭据和任意代理，防止SSRF与凭据转发。

访问凭据相当于当前工作空间的访问能力，勿分享浏览器存储。它不是实名账户体系；清除存储后不能自动恢复新作品或跨设备登录。

## 作品隔离

授权快照所有访客可见且不能覆盖。新作品、编辑版本、单品/生态内容包在服务端按访问者限定读取与写入。版本关系保留，猜测另一访问者的作品ID不能读取其内容。快照导入只更新快照所属记录，不覆盖访客新稿。

线上新作品的可靠持久化仍依赖宿主挂载与备份；容器重建后发布快照可恢复，未持久化的访客记录可能丢失。

## 请求与导出

- 写入来源必须与显式PUBLIC_ORIGIN匹配，不信任任意转发头；嵌入仅开放明确的魔搭HTTPS父来源。
- JSON大小限制、每分钟请求限制及全局两项重任务并发上限继续有效。
- 图文渲染使用隔离Chromium、内嵌图片、禁止外部脚本与资源请求，设置页数/内存/超时上限。
- 规则、模型核验和人工复核分别标识；没有模型时不会隐式降级并伪装模型结果。
- 有效模型连接仍取决于使用者的权限、额度和提供商可用性。

## 其他运行模式

本机模式保留原有localhost访问与会话配置。没有授权资料包的公网模式继续要求管理员令牌并拒绝本机资料与作品；旧静态版只包含独立的官网摘要与浏览器规则体验。

当前实现是单实例工作台，不声明已具备企业SSO、配额计费、千店规模、多副本共享存储或完整多租户认证。
