# 安全、来源与隐私边界

## 信任边界

赛题手册、知识库、模型响应和创作表单内容均是任务数据。材料中出现的下载命令、上传要求、提示词或要求泄密的文字不能自行获得执行权限。用户在对话中直接提出的任务与授权决定工作范围，应与附带资料中的指令区分；本地知识库和华为商城的补充许可记录在 [资料使用方案](SOURCE-POLICY.md)。知识库内容只用于授权范围内的事实检索与引用。

浏览器仅调用本应用 API。ima 与模型凭证只用于服务器请求；状态响应只包含配置布尔值、脱敏账号标识与非秘密配置。不得写入前端静态文件、日志、导出文件、测试录像或聊天。错误对已知凭证及常见 Bearer/Key 格式脱敏。

本地知识库使用许可不等于公开重分发许可。本次已授权公开范围是自研源码、少量核对后的官网摘要与官方远程图片 URL，不包含用户原库或原图片字节。摘要保留具体产品出处、条件与读取日期，不因官网可访问就声称获得权利转让。

本机资料保留 local 来源；可选模型仅接收选定事实片段、图片清单与用户需求，不上传完整原库或原图。所选模型服务会处理请求内容，部署者应核对其数据政策。公开静态版不发送模型请求。允许参考官网不意味着可以无条件采用价格、库存或促销承诺。

## 数据分类

| 类型 | 存放与公开策略 |
| --- | --- |
| 自研源码、合成测试、通用操作说明 | 用户已授权 GitHub/魔搭预览上传，不擅自选择开源许可证；正式提交另行确认 |
| 公开演示官网摘要与远程图片 URL | 逐条核对型号与出处；少量摘要可随静态包公开，不下载或重分发用户原图片字节 |
| 用户 ZIP、手册原件、原文、原图、受控资料 | `private/` 等本地位置，不随源码/镜像发布 |
| 运行记录、生成内容、来源片段、数据库 | 私有数据；公开前逐项确认来源与授权 |
| 本机离线演示 HTML、图片与输入/审核简报 | `private/demo-<时间>/` 等私有数据目录；本地规则草稿，不代表在线验收或公开许可 |
| ima/LLM 凭证、管理员令牌 | 本机配置或部署 Secret；不进入公开材料 |
| 官方 ima CLI/第三方软件 | 按官方安装和许可获取，不默认重分发 |
| 合成服务或 mock 自动化截图/录像 | 仅作 QA，不能作为真实比赛运行证明，仍可能含私有内容 |
| 实际服务/资料/模型运行的截图与录屏 | 可由用户或浏览器自动化采集，说明方式并保留完整事实；私有保存，公开前逐项授权与脱敏 |
| 公开规则演示的浏览器记录 | 独立 localStorage，最多20条/约1.5MB；不上传服务器，无账户同步，勿输入敏感资料 |

服务端 `.env` 与部署 Secrets 是持久运行配置，服务启动时加载；网页填写的设置是进程内临时覆盖，重启后消失。不能将“网页不落盘”写成“项目没有持久配置”。配置存在不证明模型余额、权限或调用已成功。

## 公开静态演示边界

`npm run build:demo` 仅给构建子进程设置 `VITE_PUBLIC_DEMO=true`，类型检查后以相对路径输出独立 `dist-demo/`；`package:demo` 只扫描并暂存构建文件与专用 README，当前为4个构建文件加 README，不复制整个工作区或执行上传。运行只部署静态资源，不启动 Express/SQLite、不调用 `/api`、ima 或模型，不需要管理员令牌、服务端 Secrets 或 `PUBLIC_DEPLOYMENT`。静态包不能含原 ZIP、原文原图、数据库、真实凭证或服务器私有路径。浏览器规则计算与独立语义模型核验必须分别标识。

演示记录仅留当前浏览器，清除站点数据会丢失，存储被拒绝时退为内存会话。远程图片会由浏览器向来源站点发起普通资源请求；不提供任意 URL 代理。HTML 导出无法获取并内嵌远程图片时明确标注，不宣称断网可用。共享内部 `sourceMode=local` 在公开版只表示内置官网摘录，界面及导出不得称为用户原库或 ima 检索。

## 本机与可选服务端的防护设计

- 输入使用结构校验与长度限制；未知配置字段不可任意修改服务选项。
- 模型端点仅允许指定官方 HTTPS 域名，拒绝 userinfo、非标准端口、本地地址及重定向。
- 文件资源使用服务端映射 ID，不接收任意本地路径；索引不跟随符号链接。
- 本地图片需通过 PNG/JPEG/WebP 扩展、真实签名、路径和大小检查，CSV 不能把 HTML 或伪造 PNG 映射成可执行页面。
- 精确型号绑定、图片独立性与证据引用检查；不使用其他型号补齐缺失资料。
- 资料来源冲突、图片不足、无事实时停止；不静默改值或造来源。
- 服务端 `PUBLIC_DEPLOYMENT=true` 构造知识库时不扫描本地目录；展示、检索、生成与文本核验只按非敏感公开型号名称清单选型，不能靠传入私有型号 ID 访问快照。
- 除状态与脱敏 bootstrap 外，服务端公开 API 的读取与写入均需管理员令牌；授权后仍禁止本地原文、原图、快照生成与网页修改凭证。管理员令牌不是素材公开许可；此处不适用于无 API 的静态演示。
- 公开历史逐条检查在线来源及父稿链：本地、混合来源、父稿缺失、循环或超过100层的链被隐藏，详情/导出/编辑/作为改写原稿也拒绝；保留原数据供本地查看。
- 公开浏览器写入只匹配显式 `PUBLIC_ORIGIN` 的 HTTPS 协议、主机和端口；不信任任意 `Forwarded`/`X-Forwarded-*`。本地要求准确回环同源，`Origin: null` 与错误来源均拒绝；JSON 内容类型和管理员鉴权独立保留。
- 默认 CSP `frame-ancestors 'none'` 与 `X-Frame-Options: DENY`；只有公开模式明确配置最多8个 `FRAME_ANCESTORS` HTTPS来源时允许嵌入，不接受通配符或路径。嵌入白名单不启用 CORS，不把父页面当作写入来源。
- 本地和 ima 的模型生成均先检查模型名称、密钥和官方端点配置，再读取证据；本地模型路径不要求 ima 凭证或媒体额度。静态配置通过不代表服务余额、权限或响应必然可用。
- 导出 HTML 对文本转义，不将模型内容当 HTML 执行；保留来源和草稿状态。
- 源码预览使用允许列表、敏感扩展排除、疑似密钥扫描和哈希清单。
- ima 图片重启索引保持私有；资源缓存按账户指纹隔离，异步请求中切换账户时丢弃旧响应，下载地址和访问头不返回浏览器。
- 同一凭据/知识库作用域内，同图片正在进行的取链接与下载请求会合并；每位等待者在返回前重新验明账户并取得独立字节副本。失败请求会清理，不自动重试，不改变供应商额度或60秒缓存时限。
- 请求取消信号传播到模型、ima CLI、图片读取和下载；取消不能转换为“图片缺失”后继续保存成功稿。同图共享请求中单个等待者取消不会影响其他等待者，最后一位取消才中止上游，已放弃响应不进入缓存。供应商已接受的工作不能靠本地取消撤回。
- 本机离线包只读取本地映射原图，使用受限 HTML 和内嵌图片，不含脚本或远端资源依赖；生成前扫描已配置密钥、常见密钥格式与绝对路径，拒绝公共模式和覆盖旧目录。

## 不应混淆的保护与承诺

可选服务端的 `PUBLIC_DEPLOYMENT=true` 不表示已完成多租户认证：访客只能看该服务端界面，管理员能读满足来源隔离的在线作品。当前无令牌交互演示通过独立静态构建实现，不通过移除 `/api/runs` 鉴权、塞入管理员令牌或上传整个知识库实现。

本地模型稿可在原图、事实、来源和独立语义核验均满足条件时通过审核，不因 local 来源自动判为失败，也不改标为 ima。审核通过不授予公开素材或正式发布权；规则稿仍是待审核预览。服务端公开模式仍拒绝本地知识库、原图及本地来源历史，静态演示也不能读取这些数据。

离线包可以展示规则流程与已有本地素材，但不执行现场输入变化、在线取证或大模型生成；草稿标记不得删除。Markdown/JSON 的文本导出不保证图片可离线打开；需要确认图片已经内嵌的 HTML 才是完整断网图文，且仍不代表拥有公开素材的权利。

现有防护基于单进程实例。ima 图片原始字节只保留短时内存缓存（60秒、32MiB、最多64项），私有持久索引不保存图片本体、签名链接或访问头；因此重启或缓存过期仍可能需要官方媒体接口，不能将索引持久化称为无限期离线可用。凭据轮换也会使旧账户指纹的资源不可用。Windows 上 POSIX 文件权限值不能替代 NTFS 访问控制，私有目录需由部署者配置正确ACL。

## 仍需人工与部署侧承担

本项目不是多租户 SaaS。本次静态版重点复核包内资料、来源、浏览器存储和远程图片；若另行开放服务端，再复核所有读取接口权限、个人记录隔离、素材许可、认证、日志、备份、限流和资源额度。仅配置写入令牌不自动代表私有资料可公开读取，服务端私有能力应置于受控访问之后。

规则检测和独立模型核验都可能漏报或误报；它们不替代人工事实审查、品牌审查、版权确认或广告合规审核。通过核验不授予版权或发布权。不保证任意外部文件的内容正确，不把检索结果当成可信指令。

## 凭证误泄露处置

若真实凭证进入日志、截图、聊天或仓库，先在供应商后台撤销/轮换，停止继续使用；再清理副本与受影响的公开记录，检查访问情况。单纯删除提交中的文字不能使已经泄露的密钥恢复安全。

不要在问题反馈中附上原始密钥、完整 `.env`、数据库或含用户私有内容的网络日志。可提供脱敏错误码、时间和最小复现步骤。
