# 展示案例

三篇作品均由实际模型调用生成，使用同一款 HUAWEI MateBook 14 酷睿 Ultra，面向不同受众与发布平台。可在在线工作台的“作品记录”中按标题打开完整图文、依据及导出成品。

| 平台 | 作品 | 正文字数 |
| --- | --- | --- |
| 小红书 | [开学带电脑出门，我想先安排好图书馆的那一页](examples/xiaohongshu.md) | 646 |
| 微信公众号 | [MateBook 14 值得放进图表型方案的会前准备里](examples/wechat.md) | 942 |
| 门店朋友圈 | [想换家用电脑、周末爱挑照片的你，可以看看这台](examples/moments.md) | 202 |

字数统计导语、各段正文与行动引导的非空白字符（含标点）；标题、小标题、话题与说明不计入。三篇均完成事实、图片与合规核验，核验辅助审阅，不代表已经验证传播效果。
