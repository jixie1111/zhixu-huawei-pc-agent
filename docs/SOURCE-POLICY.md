# 当前资料使用与生成方案

更新于2026-10-18。原始赛题手册不修改；本文件记录用户在开发过程中的补充指示，以及对应的实现和验收边界。

## 当前优先交付：公开免 API 交互演示

用户最新要求参考免 API 演示尽快上传 GitHub 与魔搭，已授权上架预览。[GitHub 仓库](https://github.com/jixie1111/zhixu-huawei-pc-agent)已创建，源码尚未推送；[魔搭创空间](https://modelscope.cn/studios/jixie1111/zhixu-huawei-pc-demo)首次部署已 Running、首页HTTP200。修正版已完成本地构建，第二次部署进行中，最终线上交互验证尚未完成。此次上架不是正式比赛提交，不再要求先完成模型配置。

公开版使用 `npm run build:demo` 跨平台完成类型检查与静态构建（子进程设置 `VITE_PUBLIC_DEMO=true`，输出独立 `dist-demo/`，相对路径 `base=./`），默认规则编排。`preview:demo` 在4174端口预览，`package:demo` 只扫描并暂存构建文件及专用 README。资料仅限少量逐条核对后的官网摘要、明确产品页出处与官网远程图片 URL；不公开用户 ZIP、原文、原图片字节、数据库或密钥。不把公开资料摘要冒充本地原库或 ima 实时检索。静态版不调用真实模型，结果始终标为规则演示，不宣称独立大模型核验或正式 AI 验收已通过。

官网摘要需保留型号、年款、系统/配置条件及读取日期，图片需对应具体型号。官网可访问不等于权利转让；保留出处与品牌权利说明，不捏造授权。远程图片依赖来源站点网络与可用性，失效时如实显示，不用相似型号替换。

## 本机完整知识库与可选模型

用户转述主办方允许将提供的知识库文件部署到本地调用，并要求采用此方案。本机完整版保留完整授权资料与原图，默认规则预览；显式选择模型时执行“本地知识库取证 → 模型创作 → 原图及事实核验 → 修改与导出”。两种本地方式均不以 ima 媒体额度恢复为前置条件。原始 ZIP 已解压并按型号建立索引，无需重复上传到远端服务。

此许可仅用于用户要求的本地读取；不能推断原始库、图片、数据库可公开上传。所有结果保留local来源、实际模型名称、原始资料标题和链接，不改标为ima。ima仍作为可选来源，其真实接入状态单独记录。

本机 API 字段独立表达来源与生成方式：`mode=local|ima`；本地模型创作用 `generation=model`，规则预览用 `generation=rules`。省略 generation 的 local 请求仍为规则预览；界面按最新意愿默认规则，选择模型后缺配置明确提示，不把规则结果伪装成模型输出。ima 来源始终调用模型。静态演示不调用这些服务端 API。

## 模型并非指定的付费比赛材料

赛题手册第3页允许调用公开大模型，不要求自研基础大模型；第4、5页要求输出随人群、场景与平台实质变化，不能只是固定模板，且不能只转发ima写作结果。手册没有要求购买某家服务、某个模型或单独提交模型API Key。

本项目可选的模型路径使用兼容 Chat Completions 的模型完成写作、任意要求改写和独立语义核验；只有选择这条路径才需要可用模型配置。模型服务地址、模型 ID、Key 是运行配置，不是要求用户提交给组委会的材料。API Key 不能出现在说明书、源码包或录屏中。公开规则演示与本地规则预览无需模型，但不能据此声称完成高质量自由创作和真实模型验收。

## 华为商城补充参考

用户另行转述主办方允许资料不足时参考 `https://www.vmall.com/`。每条补充事实须核对具体型号、年份、操作系统和配置，保留明确的产品页链接、读取日期和原文条件，再纳入证据；商城首页只能证明网站入口，不能作为具体参数依据。不同资料冲突时保留冲突，不直接覆盖原库。

此前仅检查商城首页 HTTP200、标题“华为商城VMALL”，不能将此记录当作产品参数取证。公开演示新增的官网资料以逐条保存的具体产品来源和复核记录为准，不批量公开原库，不导入未经型号核对的参数。价格、促销、库存和补贴仍需要当前有效依据与人工确认；本项目现有金额/权益承诺限制未因允许参考商城而解除。

## 正式证据与录屏

按用户补充许可，正式 AI 验收仍应采集至少三组本地知识库＋真实模型结果，覆盖至少两场景和两平台；不得把公开规则演示或现有三份本地规则备用稿冒充模型成稿。模型输出、原图、来源、输入、版本、核验和失败状态都需可追溯。目前真实模型案例与模型录屏尚未完成，不阻塞先上架规则预览。

实际运行录屏可以由用户或浏览器自动化操作。公开规则版的真实录屏证明规则交互可用，必须标为非 LLM；正式模型证据必须来自实际资料与真实模型服务。不允许拦截接口替换成 mock 结果，也不能用静态图或剪辑掩盖失败；自动化操作方式应如实说明。现有 3101 合成测试截图和录像仍只作 QA 证据。全程不用 computer use。

当前公开规则版已取得本地桌面/手机 e2e 2/2及额外补测3/3通过、三场景九份实际导出和0 API调用证据。e2e 中人为阻断官网图片的分支只证明失败提示正确；另一组实际导出成功内嵌3/2/1张官网图片。它们均不计入三组正式模型案例，也不替代第二次部署后的最终线上实测。
