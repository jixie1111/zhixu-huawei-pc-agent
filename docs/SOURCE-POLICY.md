# 资料与生成边界

## 公开体验

公开站只使用独立核对的华为官网精简摘要与官网图片 URL。每条事实保留具体型号、来源标题、链接、读取时间和配置条件；每张图绑定同一型号。当前公开集合见 `src/demo-evidence.ts`。

公开官网可访问不等于获得素材权利转让。保留出处及品牌权利说明，不批量下载、再分发原始知识库或原图。远程图片失效时显示缺图，不用相近型号补齐。

公开页使用浏览器规则整理需求和预设方向，不访问 ima 或大模型。输出始终保留规则及人工复核标识，不作为真实模型成果。

## 本地资料

用户转述主办方允许本地使用提供的知识库，并可参考官方商城补充资料。本机完整版据此读取授权目录，保留原始文件、事实和图片索引。此本地使用许可不自动延伸为公开传播许可。

ZIP、原文、原图、SQLite、模型成稿、录屏与凭据保存在私有目录，不进入公开源码或静态构建。不得从数据库抽取素材补进公开集合。

## 事实补充与冲突

补充事实必须来自具体产品页，核对型号、年款、系统和销售配置，保留原文限定与检索日期。商城首页不作为参数依据。来源冲突需人工核实，不能用模型猜测覆盖。

价格、库存、活动、补贴、服务政策与兼容性需要当前有效依据和人工确认。旧资料的事实引用存在，不代表当前动态承诺成立。

## 模型和来源分别标识

本机 `mode=local|ima` 指定证据来源，`generation=model|rules` 指定创作引擎。使用本地资料生成的模型稿仍标为 local，不能伪装成 ima 在线结果。失败时不静默降级、不伪造检索过程。

测试中的合成数据、规则体验和真实模型结果分别记录。历史真实模型验收见 [记录](REAL-MODEL-RESULTS.md)；它不代表当前每次调用、营销转化或千店规模已验证。
