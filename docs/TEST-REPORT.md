### 移动端验收修正

首轮实站脚本只将桌面浏览器缩至 390 像素。截图复核发现魔搭桌面外壳仍给 iframe 1280 像素宽，原脚本只查 iframe 内溢出，因而漏掉外层裁切。不能将该次“mobile”标签解释为真实移动端验收通过。

独立 Android 手机仿真确认魔搭移动外壳及应用均为 390 像素宽，无横向溢出。脚本已改用 Pixel 7 设备配置并同时检查宿主页面与 iframe 宽度；外层裁切会令整个验收返回失败。

第二轮 7 项操作和外层布局检查均完成，但“整页零异常”断言失败：手机初次打开及刷新时出现两次 setAttribute 异常。独立复现的堆栈定位到魔搭 `g.alicdn.com/sail-web/maas/1.1100.154/h5/9747.js`，不在本项目构建中。不能将其写成整页零错误。验收脚本现在单独保留来源明确的平台异常；应用代码或来源不明的异常仍令验收失败，不以过滤未知错误制造通过结果。

最终完整重跑：7 项交互结果通过，桌面 1440 与手机 390 像素的宿主及 iframe 宽度均匹配，无横向溢出；应用异常 0、应用 API 请求 0。另保留两条魔搭移动外壳异常，未影响本轮生成、图片显示、导出、历史和设置操作。最终截图已目视核对，手机使用折叠导航和单列输入卡片，未再出现首轮窄桌面窗口的裁切。
