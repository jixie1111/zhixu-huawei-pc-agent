# 作品说明书草稿：知序 · 华为 PC 营销图文智能体

版本：已发布预览说明。依据用户提供的《华为·产业进阶赛道·赛题手册v4》与后续要求。本文件不是正式提交，不包含编造的获奖、用户数量或营销效果。用户已授权上传；[GitHub 仓库](https://github.com/jixie1111/zhixu-huawei-pc-agent)源码已推送，首批108文件清单核验通过，本次发布附作品说明书PDF；[魔搭创空间](https://modelscope.cn/studios/jixie1111/zhixu-huawei-pc-demo)最终版Running、游客可访问，真实桌面/手机交互验收通过。作者/团队信息不编造。

## 一、作品定位

知序面向华为 PC 营销人员与门店内容运营人员，把人群、使用场景、购买阶段和发布平台转为可解释的图文方案。它在来源明确的产品事实与图片范围内创作，并把每次生成的策略、依据、内容和审查一起保存，减少型号混用、无据卖点、错配图片与违规营销表达。

系统不直接转发 ima 写作结果。自研部分负责需求校验、场景平台策略、证据、图片限制、规则检查、记录与导出；可选服务端另提供结构化模型创作与独立语义核验。按用户最新要求，本次优先上线纯浏览器免 API 规则演示，仅使用少量已核对官网摘要和远程图片 URL。本机完整版继续保留授权知识库、原图与可选模型，ima 为可选来源。两者边界见 [资料使用方案](SOURCE-POLICY.md)，原始赛题手册不修改。

## 二、核心功能

输入必须明确具体产品、目标人群、使用场景和平台，缺失时追问。八场景分别配置问题与事实优先级；四平台分别控制语气、结构、参考篇幅、行动引导和图片数。结果包括标题、导语、正文、标签、CTA、图片位置与理由。

证据按型号绑定，含来源标题、链接、模式和读取时间。图片与目标型号不一致、资料冲突、可用图片不足、事实缺失时不能靠相似内容补齐。公开版的引用匹配和数值规则属于规则检查；本机模型模式另调用独立语义核验，不能把引用 ID 存在当作含义已被验证。

创作工作台、产品知识库、作品记录、核验中心和连接设置形成完整操作路径。修改和换平台保留版本关系，编辑后重新核验，草稿导出保留未通过状态，不能通过保存或下载“洗掉”风险。

## 三、技术架构与自研范围

前端：React、TypeScript、Vite，负责表单、策略/依据/文章/核验视图和响应式工作台。公开版通过跨平台 `npm run build:demo` 完成类型检查和静态构建，使用 `VITE_PUBLIC_DEMO=true`、`base=./` 输出独立 `dist-demo/`；`preview:demo` 在4174端口预览，`package:demo` 仅暂存静态文件与专用 README。浏览器执行共享规则，不调用后台 API、ima 或模型；历史仅保存在浏览器独立 localStorage，最多20条/约1.5MB。可选本机后端使用 Node.js、Express、Zod、SQLite，提供完整资料索引、模型编排与持久化。数据模型在 `shared/` 统一，系统提示词在 `prompts/system.md` 单独维护。

自研范围：需求澄清、八场景四平台规则、本地知识索引、证据结构、官方 ima 调用适配、目录回退、精确型号识别、结构化生成、核验、界面、记录和导出。第三方范围：可选 ima 服务与官方 CLI、模型服务以及依赖库。本地资料来源保留 local，生成方式另行记录为模型或规则，不冒充 ima 在线取证。

界面默认规则预览，公开静态版不启用模型选项。本机用户显式选择模型后才需要配置，缺少配置时明确报错，不冒充模型结果。模型 API 是项目实现选择；手册允许公开大模型，没有要求购买指定厂商服务或向组委会提交密钥。服务地址、模型 ID 与密钥通过服务端 `.env` 或部署 Secrets 持久配置，网页设置只在当前服务进程中有效；这些配置不是公开静态预览的前提。

详见 [系统设计](ARCHITECTURE.md) 和 [部署指南](DEPLOYMENT.md)。

| 合规规则 | 拦绝对化、虚假承诺、误导价格、贬低竞品、虚构体验/数据 |

## 五、资料来源、模型接入与真实性

公开演示使用单独核对的少量官网摘要、具体产品页出处与远程官方图片 URL，不从用户 ZIP 提取公开数据。共享内部类型沿用 local，界面和导出明确标“公开官网摘录”，不是本地原库或 ima 在线取证。远程图片加载受网络与来源站点影响；HTML 导出不能内嵌时会保留未内嵌提示，不宣称完整离线图文。

用户提供的 ZIP 已解压并按型号建立索引，本机规则与模型路径均无需再次上传资料，也不依赖 ima 凭证或媒体额度。本机证据和原图保留原始资料标题、链接、型号和 local 来源。选择模型时只发送选定事实、图片清单与创作要求；原始库、原图字节和数据库不随源码包或镜像公开。

用户另行允许资料不足时参考华为商城。官网事实须逐条核对具体型号、年款、系统和配置，保留产品页链接、读取日期和适用条件；首页可访问不能作为参数依据，冲突不覆盖原库。公开集合以逐条保存的官方来源与复核记录为准，不批量公开原库。

可选 ima 路径使用用户账号及指定共享库，通过服务器配置官方凭证。界面区分“已配置”和“真实连接成功”，显示脱敏账号与库名称。检索围绕具体型号，必要时目录回退；外部响应中的操作性语句不作为指令执行。此前真实连接、指定型号12个事实维度与4张图片获取曾成功；随后重启复验前2张图片成功，后2张被每日资料额度阻断，已停止进一步真实调用。ima 完整复验待供应商条件允许，但不阻塞本地模型主路径。

真实模型尚未配置，尚未完成真实模型生成与独立核验；这不阻塞先上架规则演示。具体证据以 [测试报告](TEST-REPORT.md) 为准；未实际完成的部分保留“待验证”，不以公开规则稿、mock 测试或成功动画代替模型运行证据。

## 六、事实与营销合规

核验覆盖引用存在性与型号、数字参数支持、图片型号与数目、来源、冲突、平台规范及风险表达。对价格、补贴、库存、活动、奖项、销量与体验，缺少当前授权依据时不写。软件兼容与使用效果先核对具体系统/版本/任务，不作无条件保证。

本地模型结果在事实和原图有效、来源一致、独立语义核验完成且无阻断或警告时可以通过审核；local 来源仍明确展示。规则预览不算模型验收通过。核验不是法律意见，素材授权和正式发布需人工确认；已发现的问题保留到结果与导出中，未达到发布条件只能作为待审草稿。
