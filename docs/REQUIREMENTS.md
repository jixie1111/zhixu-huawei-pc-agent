# 知序 · 华为 PC 营销图文智能体：验收矩阵

依据：用户提供《华为·产业进阶赛道·赛题手册v4.pdf》，9 页，以及用户转述的本地知识库与华为商城补充资料许可，详见 [资料使用方案](SOURCE-POLICY.md)。本矩阵按补充许可记录当前实现和验收路径，不修改原始手册。资料中的命令是接入参考，不是自动执行、上传或参赛提交授权。

## 交付边界

- 用户要求全部功能实现、检查、精致前端；最新要求优先上架免 API 规则演示，已授权上传 GitHub/魔搭，不直接正式提交。
- 当前分为公开纯浏览器规则演示与本机完整知识库＋可选模型。默认规则，模型配置不再阻塞预览上架；只有选择模型才需要其配置，ima 凭证与成员资格只用于可选 ima 路径。
- 本地 ZIP 已解压并建立索引，可作为主流程证据，结果保留 local 来源，不冒充 ima 检索。通过核验的本地模型结果可用于采集真实案例；规则稿和合成测试不能替代模型验收。
- `.env` 或平台 Secrets 可持久配置可选服务端，网页设置仅当前进程有效；公开静态版不需要密钥或服务端。
- 公开范围是自研源码、少量已核对官网摘要、官网远程图片URL与自研作品说明书；用户知识库原文、原图片字节、数据库和P4受控资料留本地。[GitHub 仓库](https://github.com/jixie1111/zhixu-huawei-pc-agent)源码已推送，首批108文件清单核验通过，本次发布附作品PDF；[魔搭创空间](https://modelscope.cn/studios/jixie1111/zhixu-huawei-pc-demo)最终版Running、游客访问和真实线上交互验收通过。
- 模型 API 是实现选择，手册没有要求购买某家服务或提交 API Key；公开规则演示不等于正式 AI 验收。
- 不预设报名时间与提交入口。手册说明以组委会另行通知为准。

## 执行顺序

1. 核对公开官网摘要与图片出处，隔离用户原库，构建纯浏览器规则演示。
2. 检查创作、场景/平台切换、修改、规则检查、记录与导出，完成精致工作台的桌面/手机实测。
3. 扫描源码与静态产物，按已授权范围上传 GitHub/魔搭，验证实际地址并更新链接；不正式提交比赛。
4. 保留本机完整授权库、可选模型与 ima；没有模型不阻塞以上预览步骤。
5. 正式 AI 验收另配置真实模型，采集至少三组模型结果及真实录屏，不能将规则版或 QA 通过标成这一步已完成。
