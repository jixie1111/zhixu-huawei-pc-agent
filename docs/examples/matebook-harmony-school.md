# 开学电脑，屏幕和重量我都想要

课表刚排好，电脑也想早点选定。每天要背去上课，坐下来又要对着它读资料、写报告。HUAWEI MateBook 14（鸿蒙版），我最想聊的是屏幕和重量。🎒

14.2英寸OLED抗反射屏，3:2比例。挑学习电脑，我想打开一页平常读的资料：有长段文字，也有配图，把字号调成自己的习惯，再慢慢往下读。每天要看那么久的屏幕，选之前多花几分钟，很有必要。

它支持十点触控，键盘之外，还能直接伸手点屏幕。看到想选的地方，就想碰一下；需要写长段文字，再把手放回键盘。我喜欢这种多一种操作选择的感觉。第一次接触触屏电脑，也可以从这些小动作试起。

![HUAWEI MateBook 14（鸿蒙版） · 产品原图](../../published-data/knowledge/%E5%8D%8E%E4%B8%BAPC%E5%85%A8%E6%9D%BF%E5%9D%97%E6%B7%B1%E5%BA%A6%E7%9F%A5%E8%AF%86%E5%BA%93_v7/P1-%E4%BA%A7%E5%93%81%E5%8F%82%E6%95%B0%E5%BA%93/01-%E9%B8%BF%E8%92%99%E7%94%B5%E8%84%91/HUAWEI%20MateBook%2014/images/hwpc_matebook-14-harmonyos_%E5%A4%9A%E5%BD%A9%E9%85%8D%E8%89%B2%E5%A4%96%E8%A7%82_01_7e0eedb6.png)

课程报告一写就是好几段，键盘当然也要认真挑。它配了全尺寸背光键盘，触控板支持五点触控。试的时候，我会敲一段自己要交的作业，再移动光标改几个字。按键怎么按、手怎么放，还是自己试过最直接。⌨️

圆键盘款含电池约1.33kg，厚14.5mm。电脑要和课本、水杯一起出门，我会带上常用的书包，看看装进去之后，其他东西准备怎么摆。上午上课、下午去图书馆，挑电脑时把每天带的包也算进去，挺实际。

这款搭载HarmonyOS 6。准备上大学的同学，可以把课程要用的软件名称一起带来聊，按自己的专业选电脑。屏幕尺寸按圆角屏标准矩形测量，实际可视区域略小；重量会因配置、制造工艺和测量方法而有差异。

想聊聊这款和你的课表合不合拍，私信告诉我专业和常用软件就好。
