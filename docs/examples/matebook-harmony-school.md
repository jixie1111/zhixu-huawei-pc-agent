# 开学电脑，屏幕和重量我都想要

开学买电脑，想要一块喜欢的屏幕，也惦记每天背去上课的重量。HUAWEI MateBook 14（鸿蒙版），这两点可以一起聊。🎒

先看打开之后的样子：14.2英寸OLED抗反射屏，3:2比例，2880×1920分辨率。课件、论文、小组展示的提纲，开学后想拿它看的东西已经列了一串。选学习电脑，我愿意把时间花在屏幕上，毕竟以后天天都要对着它。屏幕采用圆角设计，尺寸按标准矩形测量，实际可视区域略小。

这块屏幕还支持十点触控。想直接伸手点一下的人，多了一种操作方式。翻资料时伸手碰屏幕，写作业时回到键盘，改几个字再挪动光标——想到这些日常小动作，会觉得触屏电脑挺有意思。

![HUAWEI MateBook 14（鸿蒙版） · 产品原图](../../published-data/knowledge/%E5%8D%8E%E4%B8%BAPC%E5%85%A8%E6%9D%BF%E5%9D%97%E6%B7%B1%E5%BA%A6%E7%9F%A5%E8%AF%86%E5%BA%93_v7/P1-%E4%BA%A7%E5%93%81%E5%8F%82%E6%95%B0%E5%BA%93/01-%E9%B8%BF%E8%92%99%E7%94%B5%E8%84%91/HUAWEI%20MateBook%2014/images/hwpc_matebook-14-harmonyos_%E5%A4%9A%E5%BD%A9%E9%85%8D%E8%89%B2%E5%A4%96%E8%A7%82_01_7e0eedb6.png)

全尺寸背光键盘、支持五点触控的触控板也在。写课程报告，我会想认真试试键盘；读资料时，又会留意触控板怎么用。手边要有按键，也想保留伸手点屏幕的选择——这是我挑开学电脑时会有的一点小贪心。⌨️

合上电脑，话题就轮到每天带出门的机身。圆键盘款含电池约1.33kg，厚14.5mm；实际机身重量会因配置、制造工艺和测量方法而有差异。上午上课、下午去图书馆，电脑会跟着人换地方。对经常带电脑出门的同学，重量这一项确实很难跳过。

它用的是HarmonyOS 6和麒麟X90。内存有24GB、32GB，存储有512GB、1TB可选。想了解鸿蒙电脑的同学，可以从这款看起，再按自己的课程安排聊具体配置。第一次给大学买电脑，有疑问就直接问，尤其是已经列进课表的那几门专业课。

你挑开学电脑，会先看屏幕，还是每天要背的重量？
